# CyberLab Academy — versión final actualizada

## Incluye
- 100 niveles con enunciados específicos.
- Respuesta, pista y explicación en cada nivel.
- Enter para comprobar.
- +50 XP por nivel.
- Niveles 1–5 gratuitos; desde el 6, sesión local de demostración.
- 12 módulos de teoría conectados con sus PDFs.
- PDFs 2026 adicionales dentro de `pdf/`.

## Estructura obligatoria
`index.html` y la carpeta `pdf/` deben permanecer al mismo nivel.

## Abrir sin problemas
En la carpeta descomprimida:

`python -m http.server 8000`

Luego:

`http://localhost:8000/`

Esto evita las restricciones que algunos navegadores aplican al abrir directamente un HTML mediante `file://`.

Los ejercicios ofensivos están pensados exclusivamente para laboratorios propios, aislados o autorizados.
El login es una demo local; producción requiere backend.
